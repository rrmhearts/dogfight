A simplistic, turn-based 2D flight simulator in C++ that focuses on the architectural structure and interaction of the different systems: movement, radar, laser designation, and weapon firing. 

It is implemented it as a console-based ASCII game. Instead of hardware arrow keys (which require OS-specific libraries to read without pressing Enter), it uses the standard `W`, `A`, `S`, `D` keys for movement.

### How this Architecture Works:

1.  **Component-Based Design:** Instead of putting all the code in one massive `Plane` class, I separated the capabilities into distinct classes: `Radar`, `LaserDesignator`, and `WeaponSystem`. The `Plane` class simply *owns* an instance of each of these systems. This mirrors how software in actual flight simulators (and game engines) is often structured.
2.  **The Radar:** Uses a simple Euclidean math formula ($a^2 + b^2 = c^2$) to calculate the distance between your plane and all active targets. It generates a list of targets that fall within its `scanRadius`.
3.  **The Laser Designator:** Takes the list of nearby targets generated by the Radar and keeps a pointer (`Target*`) to the one you currently have selected. Pressing the 'T' key loops through available targets.
4.  **Firing Weapons:** The `WeaponSystem` checks if you have ammo and if the Laser Designator has provided a valid target. If both are true, it marks the target as destroyed (`isActive = false`), which removes it from the map.

### How to run and play it:
1. Copy the code into a file named `FlightSimulator.cpp`.
2. Compile it using any standard C++ compiler. For example: `g++ FlightSimulator.cpp -o FlightSimulator`
3. Run the executable. 
4. The map will display your plane as `^` (or `< > v` depending on direction) and targets as `T`.
5. Move close to a target using `W`, `A`, `S`, `D` (press Enter after your letter).
6. Press `R` + Enter to ensure they are in radar range. 
7. Press `T` + Enter to lock on (the target changes to an `X` on the map).
8. Press `F` + Enter to fire.
